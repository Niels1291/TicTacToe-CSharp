# TicTacToe — C# Console Game



A simple TicTacToe console application built with C# and .NET.



### About this project



I created this project to refresh my C# knowledge and practice object-oriented programming after previously working professionally with C# and .NET.



#### Learning goals



* Object-oriented programming (OOP)
* Encapsulation and class responsibilities
* Working with collections and dictionaries
* Game logic and input validation
* Writing readable and maintainable C# code
* Version control with Git



#### Features



* Human player versus computer
* Random computer moves
* Input validation
* Win detection



#### Future improvements



* Draw detection and game-over messages
* Unit tests
* Improved player architecture using interfaces and polymorphism
* Refactoring and code cleanup
